How it works

Learn normal. Flag the rest.

DINOv2 turns every patch into a feature vector; PatchCore scores each against a bank of flawless samples. Whatever sits far from normal becomes a heatmap — and, thresholded, a box. No trained detector, no labels.

Defect-free fabric → DINOv2 features → Nearest-neighbour distance → Score · Heatmap · Boxes
